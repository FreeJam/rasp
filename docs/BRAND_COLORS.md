# Брендовые цвета FreeJam

Палитра бренда FreeJam (FJ): тёмная тема с неоновым градиентом. Этот документ можно использовать как основу для будущих проектов.

Все значения совпадают с файлами `app/src/main/res/values/colors.xml` и `app/src/main/java/com/example/qrscanner/ui/theme/`.

---

## 1. Неоновый градиент (главный акцент)

Фирменный градиент: **синий → фиолетовый → розовый**. Переливается плавно, полный цикл 4 секунды, палитра по кругу.

| Название | HEX | Роль |
|---|---|---|
| Neon Blue | `#3B82F6` | Начало градиента, акцент, вторичный цвет |
| Neon Purple | `#8B5CF6` | Середина градиента, основной цвет Material |
| Neon Pink | `#F472B6` | Конец градиента, яркие акценты |

**Как использовать:**
- Градиент применяется к коротким акцентным элементам: подписям, иконкам, уголкам рамок, выбранному пункту навигации, кнопкам.
- Не заливайте большие поверхности градиентом целиком. Фон и карточки должны оставаться тёмными и спокойными.
- Анимацию делайте медленной (3–5 секунд на цикл), без резких переходов.

**Пример на Kotlin (Jetpack Compose):**
```kotlin
fun neonAt(phase: Float): Color {
    val x = ((phase % 1f) + 1f) % 1f * 3f
    return when {
        x < 1f -> lerp(NeonBlue, NeonPurple, x)
        x < 2f -> lerp(NeonPurple, NeonPink, x - 1f)
        else -> lerp(NeonPink, NeonBlue, x - 2f)
    }
}
```

## 2. Основная палитра интерфейса

| Название | HEX | Роль |
|---|---|---|
| FJ Dark Background | `#0F1115` | Основной фон приложения |
| FJ Card Background | `#181B22` | Карточки, панель навигации |
| FJ Card Hover | `#212530` | Карточки в состоянии наведения, приподнятые поверхности |
| FJ Border | `#2D323E` | Тонкие бордеры карточек, разделители |
| FJ Text Primary | `#FFFFFF` | Основной текст и иконки |
| FJ Text Secondary | `#9CA3AF` | Вторичный текст, неактивные иконки, подписи |

**Правило контраста:** белый текст на `#0F1115` и `#181B22` — основной вариант. Вторичный текст `#9CA3AF` только для описаний и метаданных.

## 4. Системные и служебные цвета

| Название | HEX | Роль |
|---|---|---|
| Error | `#FF6B6B` | Ошибки, опасные действия (используется как тёмный вариант, без ярко-красного) |
| Light Background | `#F7F8FA` | Светлая тема: фон |
| Light Surface Container | `#F0F2F5` | Светлая тема: карточки |
| Light Text | `#111318` | Светлая тема: основной текст |

Светлая тема не является основной. Она нужна для совместимости и должна использовать ту же неоновую палитру.

## 5. Выведенные из бренда цвета Material 3

Для тёмной темы в Material 3 задайте роли так:

| Роль Material | Значение |
|---|---|
| `primary` | Neon Purple `#8B5CF6` |
| `primaryContainer` | `#2E1F5E` (тёмный фиолетовый) |
| `secondary` | Neon Blue `#3B82F6` |
| `tertiary` | Neon Pink `#F472B6` |
| `background` | FJ Dark Background `#0F1115` |
| `surface` | FJ Card Background `#181B22` |
| `surfaceContainerHigh` | FJ Card Hover `#212530` |
| `onSurface` / `onBackground` | FJ Text Primary `#FFFFFF` |
| `onSurfaceVariant` | FJ Text Secondary `#9CA3AF` |
| `outlineVariant` | FJ Border `#2D323E` |

| FJ Primary (красный) | `#F30000` | Заменён неоновым градиентом, ярко-красный не сочетался с палитрой |
| FJ Primary Variant (тёмно-красный) | `#C40000` | Заменён фиолетовым и синим |

## 7. Правила для будущих проектов

1. **Тёмный фон по умолчанию.** Светлая тема — опция, а не основной режим.
2. **Один акцент — градиент.** Синий → фиолетовый → розовый. Не добавляйте новые яркие основные цвета без причины.
3. **Не используйте чистый красный как акцент** (`#F30000`, `#FF0000`). Для ошибок и опасных действий берите `#FF6B6B`.
4. **Радиусы скруглений:** 12 dp (мелкие элементы), 16 dp (кнопки и поля), 24 dp (карточки и крупные блоки).
5. **Анимации плавные:** циклы 3–5 секунд, линейная или синусоидальная интерполяция, без рывков.
6. **Текст на градиенте** — только белый или очень светлый. Подписи на градиенте делайте жирными (`SemiBold` и выше).
