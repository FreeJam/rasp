# Расписание уроков

Школьное расписание для 10–11 классов: дни недели слева, уроки сверху, мгновенное
переключение между классами, учителями и кабинетами. Статика без зависимостей,
данные собираются из экспорта **aSc Timetables**.

Живая версия: https://freejam.online/rasp/

## Что умеет

- Три режима: **класс**, **учитель**, **кабинет** — одна и та же сетка, разный контекст в ячейках.
- Дни идут строками, уроки — столбцами; шапка дней закреплена при горизонтальной прокрутке.
- Фильтры: тип занятий (уроки / внеурочные / элективные), подгруппа (1 гр., 2 гр., мальчики, девочки).
- Кнопка «Сбросить» в панели появляется, только когда фильтры активны.
- Поиск по классам, учителям, кабинетам и предметам; у предмета — список классов и часов.
- Карточка урока: предмет, кабинет, учитель; параллельные подгруппы показываются двумя половинами ячейки.
- «Сейчас»: текущий урок, перемена, время до звонка; текущий столбец и строка подсвечиваются.
- Звонки, печать недели, тёмная и светлая темы, три размера карточек, ссылка на конкретный класс (`#c=3`).
- Тёмная тема по умолчанию — палитра из `docs/BRAND_COLORS.md`.

## Структура

```
index.html          разметка (панель, сетка, шиты)
css/app.css         дизайн-система: iOS-стиль + брендовая палитра FreeJam
js/app.js           данные, индексы, рендер сетки, шиты, фильтры
data/schedule.json  собранное расписание (компактный формат с индексами)
build.py            сборка JSON из docs/20.xml
docs/20.xml         исходный экспорт aSc Timetables
docs/BRAND_COLORS.md палитра бренда
```

### Формат данных

`grid[classId]["день"]["урок"]` — массив записей
`[предмет, [учителя], [кабинеты], [группы], [классы]]`, где все значения — индексы
в общих массивах `subjects / teachers / rooms / groups / classes`.
Индексы учителей и кабинетов приложение строит само при загрузке.

## Обновить расписание

```bash
# заменить docs/20.xml на новый экспорт из aSc («Экспорт → XML»)
python3 build.py
# проверить вывод: количество карточек и занятых клеток
```

Затем обновить `?v=` у `css/app.css` и `js/app.js` в `index.html`, если менялись стили/код.

## Локальный запуск

```bash
python3 -m http.server 8080     # из папки проекта, открыть http://localhost:8080
```

## Публикация

Сайт отдаётся nginx как статика по симлинку:

```bash
ln -sfn /var/www/rasp /var/www/freejam/rasp
```

Исходный XML и `build.py` лежат в веб-корне — при желании закрыть их в nginx:

```nginx
location ~ ^/rasp/(docs|build\.py)$ { return 404; }
```
